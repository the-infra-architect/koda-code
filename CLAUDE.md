# Coding Assistant Instructions

Follow `AGENTS.md` as the operating contract. Read the active mission brief, inspect the target code,
and implement only the requested outcome. Use a contained feature/fix/refactor branch, run the full
configured quality gate before delivery, and never claim success from unverified output.

Prefer clear, conventional code and proportionate architecture. Treat framework conventions,
security, typing, errors, performance, resource use, and dependency cost as part of correctness.

Never push directly to a protected branch. After a major milestone recommend conversation
compaction; after more than three repeated failures, stop guessing and hand off the exact evidence.
